# Lara, Giovannini, Cotton, Feretti, Marcaide, Marquez & Venturi (2004) — Core-Total Radio Relation

**Authors:** L. Lara, G. Giovannini, W. D. Cotton, L. Feretti, J. M. Marcaide, I. Marquez, T. Venturi
**Journal:** A&A 421, 899–911
**arXiv:** [astro-ph/0404373](https://arxiv.org/abs/astro-ph/0404373)

## Abstract

Studies a sample of large angular size FRI and FRII radio galaxies, establishing the relationship between core and total radio luminosities from VLBI observations.

## Key Result

Core-total radio luminosity relation:

$$\log_{10} L_{r,\text{core}}^{4.9\,\text{GHz}} = 4.2 + 0.77\,\log_{10} L_{r,\text{tot}}^{1.4\,\text{GHz}}$$

where luminosities are in W/Hz. This converts the total 1.4 GHz radio luminosity to the 4.9 GHz core luminosity used in the [Di Mauro+ (2014)](dimauro2014.md) gamma-ray correlation.

## Repository Use

Used by the repository in `astro_sources.py` for the core-to-total radio conversion that enters the mAGN luminosity-function chain.
